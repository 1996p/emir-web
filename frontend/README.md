# ЕМИР ЖКХ: фронтенд

React 18, TypeScript, Vite. Запуск всего проекта описан в `../README.md`.

## Как устроено

- `src/ui`: свои компоненты интерфейса (кнопки, таблицы, поля, вкладки).
- `src/domain`: типы и расчёт для показа на экране. Суммы хранятся в копейках, окончательно их считает сервер.
- `src/api`: все запросы к серверу. В режиме разработки Vite передаёт `/api` на `http://localhost:5080`.
- `src/layout`: верхняя панель, сессия и роли, общий поиск (Ctrl+K).
- `src/pages`: экраны.

Меню скрывает недоступные разделы только для удобства. Права проверяет сервер.
